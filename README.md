# Earth and Faith

A personal blog about religion, science, space, technology, history and the big questions people have always asked.

**Live site:** [earthandfaith.online](https://earthandfaith.online)

## About

Earth and Faith looks at how the world we can observe ("Earth") and the beliefs that give people meaning ("Faith") meet. Posts are written in plain English, with sources, and follow one rule: criticize ideas, not people.

## What is on the site

- Articles on religion, history, science, space and technology
- A [timeline of religions](https://earthandfaith.online/timeline/) and a [world religion map](https://earthandfaith.online/religion-map/)
- Topics page to browse posts by subject
- Reading progress bar, table of contents and back-to-top button on posts
- Dark mode that follows the device setting
- Language menu with 16 languages (Google Translate)
- Installable as an app on phones (PWA) and readable offline
- No ads and no analytics or tracking tools

## Built with

- [Jekyll](https://jekyllrb.com/) with a customized Minima theme
- [GitHub Pages](https://pages.github.com/) for hosting
- Plain HTML, CSS and a little JavaScript, with no frameworks

## Repository layout

| Path | What it holds |
|---|---|
| `_posts/` | Blog posts (`YYYY-MM-DD-title.md`) |
| `_includes/` | Reusable parts such as the header, footer and head |
| `_layouts/` | Page layouts |
| `assets/` | Styles (`main.scss`) |
| `*.md` in the root | Pages such as About, Contact, Timeline and Topics |
| `manifest.json`, `sw.js` | App (PWA) files |

## Writing a post

Create a file in `_posts/` named like `2026-10-05-my-post.md` and start it with:

    ---
    layout: post
    title: "My Post Title"
    date: 2026-10-05 10:00:00 +0000
    tags: [Science]
    ---

Then write the article in Markdown below it.
